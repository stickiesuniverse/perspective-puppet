# Perspective Puppet

3D reference for drawing comics: pose figures, set up props and find the perfect camera angle.

- **Phone / tablet app:** open https://stickiesuniverse.github.io/perspective-puppet/ in Safari, tap Share, then **Add to Home Screen**.
- **PC version:** download `PerspectivePuppet-PC.html` and double-click it.

AI building works with your own Anthropic API key (Claude), a free Google Gemini key, or Ollama on a PC.
Your saved scenes stay on your own device.
